# Contributing

Pytml 2.5 is a small browser runtime plus an inline UI preprocessor. Keep changes focused and preserve normal Python syntax.

Before opening a pull request:

```bash
npm run build
npm test
```

For inline UI changes, add or update a runnable example and a regression test. The full Pytml document compiler is planned for v3.0, so avoid turning the 2.5 preprocessor into a second language.
