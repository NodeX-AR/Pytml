# DOM

Every ordinary HTML element with a valid JavaScript identifier as its `id` is exposed to Python by name.

```html
<input id="name">
<p id="result"></p>
```

```python
result.text = "Hello " + name.value
```

The same rule applies to controls generated by the 2.5 inline preprocessor:

```html
<py1>
<btn1>Hello</btn1>
</py1>
```

becomes a real `<button id="btn1">Hello</button>` before Python executes, so:

```python
btn1.on("click", hello)
```

works through the existing runtime binding.

## Element properties

Common properties include:

- `value`
- `text`
- `html`
- `checked`
- `selected`
- `disabled`
- `visible`
- `placeholder`
- `class_name`
- `scroll_top`
- `scroll_left`
- `files`

## Events

Pytml exposes browser event data through Python callbacks. Mouse, pointer, touch, keyboard, input/change, focus/blur, wheel, scroll, drag/drop, form and media events are supported by the runtime.
